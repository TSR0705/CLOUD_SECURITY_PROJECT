1. CANONICAL RULE HIERARCHY & SPECIFICATION
--------------------------------------------------------------------------------
The Deterministic Decision Engine (packages/decision-engine) enforces rules R1–R7
in strict canonical precedence. All decisions are pure functions:
  decide(policy, fileVersion, findings) -> DecisionResult

Rules Summary:
  R1: Result Identity Verification
      Ensures finding scannedSha256, scannedStorageVersionId, and scannedSizeBytes
      strictly match the immutable file_versions ingest identity.
      Mismatch -> ERROR / DECISION_IDENTITY_MISMATCH or RESULT_IDENTITY_MISMATCH.
  R2: Required Check Completeness & Scanner Failures
      Verifies all policy.requiredChecks are present. If missing or scanner fails
      with outcome ERROR -> ERROR / CHECK_MISSING or SCANNER_ERROR.
  R3: Threat Findings Check (Malware / Exploits / Active Content)
      FAIL outcome with CRITICAL or HIGH severity -> BLOCK (e.g. MALWARE_DETECTED).
  R2/R3 Precedence:
      Confirmed threat (R3 BLOCK) strictly outranks scanner error or omission (R2 ERROR).
      If an artifact contains confirmed malware and another check times out,
      verdict is BLOCK, never ERROR.
  R4: Detector Disagreement / Type Undetermined
      Discrepancies in magic bytes, MIME, or extension -> QUARANTINE or BLOCK per policy.
  R5: Archive Structural Integrity & Bomb Violations
      Bomb ratio exceeded, Zip Slip traversal, overlapping entries -> BLOCK.
  R6: Cumulative Risk Score Threshold
      Weighted sum of findings evaluated against policy.riskThreshold (BLOCK)
      and policy.manualReviewThreshold (QUARANTINE).
  R7: Clean Verification
      All checks passed without threats or errors -> ALLOW / ALL_CHECKS_PASSED.
