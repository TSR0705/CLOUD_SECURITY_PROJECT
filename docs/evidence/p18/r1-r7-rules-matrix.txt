1. CANONICAL RULE HIERARCHY & RECONCILED SPECIFICATION
--------------------------------------------------------------------------------
The Deterministic Decision Engine (packages/decision-engine) enforces rules R1–R7
in strict canonical precedence matching the authoritative Build Plan (Table 2.3),
ADR-0009, and Attack Taxonomy (T5). All decisions are pure mathematical functions:
  decide(policy, fileVersion, findings) -> DecisionResult

Rules Summary & Precedence:
  R1: Result Identity Verification
      Ensures finding scannedSha256, scannedStorageVersionId, and scannedSizeBytes
      strictly match the immutable file_versions ingest identity.
      Mismatch or invalid identity -> BLOCK / RESULT_IDENTITY_MISMATCH (Rule R1).
  R2: Required Check Completeness & Scanner Failures
      Verifies all policy.requiredChecks are present. If a required check is omitted
      from findings -> ERROR / REQUIRED_CHECK_MISSING (Rule R2).
      If a required check errors -> ERROR / <reasonCode> (e.g. SCANNER_UNAVAILABLE,
      SCAN_TIMEOUT, SCANNER_ERROR).
  R3: Threat Findings Check (Malware / Exploits / Active Content)
      FAIL outcome with CRITICAL or HIGH severity -> BLOCK (e.g. MALWARE_DETECTED).
  R2/R3 Precedence:
      Confirmed threat (R3 BLOCK) or archive structural attack (R5 BLOCK) strictly
      outranks scanner error or omission (R2 ERROR). If an artifact contains confirmed
      malware and another check times out, the verdict is BLOCK, never ERROR.
  R4: Detector Disagreement / Type Undetermined
      Discrepancies in magic bytes, MIME, or extension -> QUARANTINE or BLOCK per policy
      (primary reason: DETECTOR_DISAGREEMENT or TYPE_UNDETERMINED).
  CDR Check:
      If policy mandates content disarm and reconstruction (cdrRequired === true),
      verifies that a sanitized CDR finding with outcome PASS is present.
      If absent, fails closed via policy.onSuspicious (QUARANTINE / CDR_REQUIRED).
  R6: Cumulative Risk Score Threshold & Suspicious Findings
      - Hard block: riskScore >= policy.riskThreshold -> BLOCK.
      - Manual review threshold: riskScore >= policy.manualReviewThreshold ->
        policy.onSuspicious (QUARANTINE by default, or BLOCK).
      - Explicit suspicious findings: outcome SUSPICIOUS or medium-severity warning
        triggers policy.onSuspicious (QUARANTINE / BLOCK).
  R7: Clean Verification
      All policy and scanner checks passed cleanly without threats, errors, or
      unresolved risk -> ALLOW / ALL_CHECKS_PASSED.
