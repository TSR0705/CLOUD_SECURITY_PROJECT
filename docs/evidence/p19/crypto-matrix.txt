1. CORE CRYPTOGRAPHIC SPECIFICATION & PARAMETERS
--------------------------------------------------------------------------------
- Payload Cipher: AES-256-GCM (NIST SP 800-38D)
- Data Encryption Key (DEK): 256 bits (32 bytes) CSPRNG (node:crypto.randomBytes(32))
- Nonce / IV: 96 bits (12 bytes) CSPRNG (node:crypto.randomBytes(12))
- Authentication Tag: 128 bits (16 bytes)
- Key Wrap Algorithm: RFC 3394 AES-256 Key Wrap (id-aes256-wrap) with default ICV 0xA6A6A6A6A6A6A6A6
- Wrapped DEK Size: 40 bytes (32 bytes DEK + 8 bytes ICV)
- Master Key Encryption Key (KEK): 256 bits (32 bytes)
- Header Prefix Size: 19 bytes
- Standard Header Size: 75 bytes (19 prefix + 40 wrapped DEK + 16 auth tag)
- Minimum Envelope Size: 75 bytes (19 prefix + 40 wrapped DEK + 16 auth tag + 0 ciphertext)

3. AUTHENTICATED ADDITIONAL DATA (AAD) CANONICAL BINDING
--------------------------------------------------------------------------------
Length-prefixed binary encoding preventing delimiter collisions:
  [uint32BE(10)][ "SUG-AAD-V1"       ]
  [uint32BE(len)][ appId              ]
  [uint32BE(len)][ fileId             ]
  [uint32BE(len)][ storageVersionId   ]
  [uint32BE(64) ][ sha256Plaintext    ]

Bound Fields:
  - appId: Tenant application UUID/string
  - fileId: File UUID/string
  - storageVersionId: Immutable object storage version
  - sha256Plaintext: 64-character lowercase hexadecimal plaintext digest

Tamper & Integrity Detection:
  - Any modification to appId, fileId, storageVersionId, or sha256Plaintext
    immediately triggers AuthenticationError during verify-before-release decryption.
  - Decrypted plaintext SHA-256 digest is independently recomputed and verified
    against the authenticated sha256Plaintext before plaintext release.

--------------------------------------------------------------------------------
4. KEY PROVIDER ARCHITECTURE
--------------------------------------------------------------------------------
- KeyProvider: Abstract interface (providerId, defaultKeyReference, wrapKey, unwrapKey)
- LocalKeyProvider:
  - Loads 256-bit KEK from in-memory options, secret files (/run/secrets/kek, secretsDir), or SUG_KEK env var
  - Sanitizes keyReference and prevents path traversal out of secretsDir
  - Rejects invalid KEK lengths (< 32 or > 32 bytes) with KeyProviderError
  - Wraps DEK using RFC 3394 (32 bytes -> 40 bytes)
  - Unwraps DEK using RFC 3394 with strict integrity verification; fails closed on wrong KEK
- KmsKeyProvider:
  - Live production mode (mock: false): Fails closed with KeyProviderError
  - Hermetic unit test mode (mock: true): Simulated KMS wrapping using derived keys
  - Production Guard: Strictly forbids mock mode when NODE_ENV === 'production'
