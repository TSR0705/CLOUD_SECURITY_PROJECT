2. NORMALIZATION PIPELINE
--------------------------------------------------------------------------------
1. Container CLI Normalization:
   - Command: qpdf --qdf --object-streams=disable <input.pdf> <normalized.pdf>
   - Uncompresses object streams and linearizes PDF structure into human-readable QDF.
   - Pinned in scanner container Dockerfile: `apt-get install -y qpdf`.
2. Safe In-Process Fallback:
   - Memory-budgeted FlateDecode stream extraction via zlib.inflateSync / zlib.inflateRawSync.
   - Per-stream expansion limit: 10 MB.
   - Cumulative decompressed limit: 50 MB (guards against PDF Flate stream bombs).
   - Hex-encoded name normalization: resolves escapes such as:
     /#4a#61#76#61#53#63#72#69#70#74 -> /JavaScript
